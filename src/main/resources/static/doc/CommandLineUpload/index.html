Example

The following is a fully constructed curl command tha uploads a zipped set of DICOM files for Winston Lutz processing:

        curl --user MyUserId:MyPassword --form uploadFile=@Myfile.zip;type=application/zip https://automatedqualityassurance.org/run/WinstonLutz_8?Run=Run"&"AutoUpload=true
