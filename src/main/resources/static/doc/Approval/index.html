Approvals are how the system records the fact that test results have been reviewed and assessed.

There are three possible approval states: Initially results are initially marked as UNAPPROVED and appear in the top banner of the web page:

  • ◯ UNAPPROVED
  • ✅ APPROVED
  • ❌ REJECTED

These states follow the convention established for approving DICOM plans.

Results have been approved. The approver's ID and time of approval have been recorded.

The approval may be changed as many times as needed. Each change is recorded, but only the most recent change is displayed.

The approval state of results are listed in both the Results and Winston Lutz pages. Clicking on the approval status will show the results. This allows the user to see which results need approval.

Winston Lutz list showing approvals.

Only users designated as approvers may approve results. Approvers may set other users as approvers via the Administration / Users page. Clicking the checkbox in the Approver column will go into effect immediately.

Checking boxes grant approval rights.

Any user that is whitelisted (grants special administrative privileges) is always an approver. This provides a way to create the first approver.
